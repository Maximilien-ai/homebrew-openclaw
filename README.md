# Homebrew OpenClaw

Homebrew tap for installing [OpenClaw](https://openclaw.ai) — the open-source multiagent CLI.

## Install

```bash
brew tap maximilien-ai/openclaw
brew install openclaw
```

## Usage

```bash
openclaw --version
openclaw agents list
openclaw gateway status
```

## About

This tap installs the latest OpenClaw release from npm. It tracks the upstream [OpenClaw](https://github.com/openclaw/openclaw) project.

Tested with [ClawMax](https://github.com/Maximilien-ai/clawmax) multiagent orchestration platform.

## Update

```bash
brew upgrade openclaw
```
